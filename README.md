# MCURC说明及教程
适用于Minecraft PC的全版本下载器，用于帮助下载困难的正版用户使用。帮助无家可归的孩子们找到方向。

禁止商用，允许个人二次编辑使用但是禁止分发，分发需许可。二次编辑需保留作者及URURC署名。保留所有权利。
